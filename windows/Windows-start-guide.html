입타 Windows 시작 안내

Windows 10/11 x64용 · 코드 서명 없음 · 처음 한 번 모델 약 465 MiB 다운로드

앱을 실행하기 전에

공식 GitHub 배포처에서 EXE와 같은 버전의 .exe.sha256 파일을 받으세요. PowerShell에서 아래 명령의 결과를 SHA-256 파일과 비교하세요. 파일 이름은 받은 버전으로 바꿉니다.

Get-FileHash .\Ipta-VERSION-windows.exe -Algorithm SHA256

해시가 다르면 실행하지 말고 공식 배포처에서 다시 받으세요. 해시 일치는 파일 일치 확인이며, 코드 서명이나 안전성 보증을 대신하지 않습니다.

“Windows의 PC 보호”가 표시되나요?

입타 EXE에는 코드 서명이 없어 확인되지 않은 게시자·SmartScreen 경고가 표시될 수 있습니다. 출처를 확인하고 신뢰하는 경우에만 추가 정보 → 실행을 선택하세요.

실행 버튼이 없거나 Smart App Control 또는 조직 정책이 차단하면 관리자에게 문의하세요. 입타는 이 차단을 자동으로 해제하지 않습니다. 보안 기능을 끄도록 안내하지 않습니다.

차단된 앱은 자체 창을 표시할 수 없어, 이 문서는 EXE를 실행하지 않고 브라우저로 읽도록 별도 제공됩니다. Microsoft SmartScreen 안내

처음 한 번 모델 준비

  1. 인터넷에 연결하고 앱의 지금 받기를 누르세요. 모델은 약 465 MiB(487,601,967바이트, 약 488 MB)입니다.
  2. 진행률과 받은 용량을 확인하세요. 100% 뒤 파일 무결성 확인이 끝나야 준비 완료입니다.
  3. 실패하면 인터넷 연결·저장 공간·폴더 권한을 확인하고 다시 받기를 누르세요. 이어받기는 지원하지 않아 처음부터 다시 받습니다.

모델 위치: %APPDATA%\Ipta\Models\ggml-small.bin. 이미 준비된 모델은 다시 받지 않습니다. 첫 다운로드 전 오프라인에서는 받아 적기를 시작할 수 없습니다. 준비 후에는 인터넷 없이 받아 적을 수 있고, 온라인 다듬기는 별도로 인터넷이 필요합니다.
