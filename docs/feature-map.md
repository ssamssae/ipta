## 로컬 엔진 실측

Mac arm64 빌드의 실제 whisper worker와 기존 small 모델에 합성 음성(Yuna)을 입력했다.
입력: ‘아테나 회의는 오후 세 시입니다. 금액은 만 구천 구백 원입니다.’
출력: ‘아테나 회의는 오후 3시입니다. 금액은 19,900원입니다.’
이는 합성 음성 파일 처리 결과이며 실제 마이크·소음 환경·다른 앱 붙여넣기 결과가 아니다.

Mac 빌드는 ad-hoc 서명이며 공증·배포·설치하지 않았다. 새 설치의 모델 다운로드와 권한 허용, 실제 마이크 녹음, 타 앱 입력, Windows GUI는 실기기 확인이 남아 있다. 기존 사용자 설정·모델·클립보드는 변경하지 않았다.

## 긴 받아쓰기 보존 — 0.1.28

- 맥 Option-D / 윈도우 Alt-D로 녹음을 시작한다. 60초 이후에도 녹음 표시가 유지된다. 같은 키로 종료한다. 최대 10분이며 마지막 30초에는 남은 시간을 표시한다.
- 받아적기·다듬기 중 시작/정지 키를 한 번 더 누른다. 기존 처리와 결과를 유지한다. HUD 취소 버튼 또는 전용 취소 단축키는 즉시 취소한다.
