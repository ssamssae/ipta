| 기능 | 사전 조건·진입점·조작 | 기대 결과 | 확인 근거 |
|---|---|---|---|
| 무음 후 이전 결과 보존 | 결과가 있는 상태에서 새 녹음을 종료하되 인식 결과가 공백 | 이전 원문과 결과 유지, 자동 입력 없음 | Mac `Scripts/test_personalization_state.py`, Windows `tests/test_windows_recovery.py`의 콜백 회귀 검사 |

숫자 검사는 아라비아 숫자 토큰 대상이며 한글로 풀어 쓴 수의 의미까지 비교하지 않는다. 선택한 글을 의도적으로 편집하는 기능에는 일반 받아 적기 제한을 적용하지 않는다.

## 로컬 엔진 실측

Mac arm64 빌드의 실제 whisper worker와 기존 small 모델에 합성 음성(Yuna)을 입력했다.
입력: ‘아테나 회의는 오후 세 시입니다. 금액은 만 구천 구백 원입니다.’
출력: ‘아테나 회의는 오후 3시입니다. 금액은 19,900원입니다.’
이는 합성 음성 파일 처리 결과이며 실제 마이크·소음 환경·다른 앱 붙여넣기 결과가 아니다.

Mac 빌드는 ad-hoc 서명이며 공증·배포·설치하지 않았다. 새 설치의 모델 다운로드와 권한 허용, 실제 마이크 녹음, 타 앱 입력, Windows GUI는 실기기 확인이 남아 있다. 기존 사용자 설정·모델·클립보드는 변경하지 않았다.

## 긴 받아쓰기 보존 — 0.1.28

- 맥 Option-D / 윈도우 Alt-D로 녹음을 시작한다. 60초 이후에도 녹음 표시가 유지된다. 같은 키로 종료한다. 최대 10분이며 마지막 30초에는 남은 시간을 표시한다.
- 받아적기·다듬기 중 시작/정지 키를 한 번 더 누른다. 기존 처리와 결과를 유지한다. HUD 취소 버튼 또는 전용 취소 단축키는 즉시 취소한다.
- “첫 번째 설정을 확인해 줘. 두 번째 기록도 확인해 줘. 수정은 말고 원인만 찾아줘.”를 입력한다. 앞의 두 요청과 부정 표현을 보존한다. 숫자를 연달아 말해도 기본 정리에서 삭제하지 않는다.
- 긴 원문에 대해 출력 한도로 중단된 AI 응답 또는 원문보다 크게 짧은 응답을 받으면 기본 받아쓰기 결과를 유지한다. 의도적인 선택 글 요약에는 길이 보존 검사를 적용하지 않는다.
- 연속 받아쓰기에서 맥은 준비된 인식 엔진을 재사용한다. 양 플랫폼은 긴 녹음 중에도 엔진을 준비 상태로 유지한다. 녹음 길이에 맞춘 추론 제한시간은 최대 20분이다.
- 회귀: `python3 Scripts/test_personalization.py`, `python3 Scripts/test_personalization_state.py`, `python3 Scripts/test_warm_transcriber.py`, `bash windows/scripts/test_windows.sh`. Windows 녹음 회귀는 가상 시계와 입력 스트림으로 75초 녹음을 확인한다.
- 음성 인식 자체의 오인식은 별개다. 원문 기록 설정을 임의로 켜지 않으며 진단 로그에는 길이와 처리 시간만 남긴다.
